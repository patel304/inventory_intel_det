# Limitations

- Synthetic data evaluation does not establish real-world generalization or production accuracy.
- Estimated loss uses SKU unit cost and does not include tax, promotions, recovery, or accounting adjustments.
- Authentication and role-based authorization are not implemented in the current demo scope.
- The application requires the existing MySQL database and its migrations/schema.
- Operational deployment, backups, observability, and security hardening remain separate production-readiness tasks.
